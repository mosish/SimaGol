# Storefront imagery

The five JPEG assets in `public/images/` were generated for this prototype using OpenAI image generation. They depict illustrative arrangements. Replace them with photographs of the shop’s own arrangements when preparing the production catalog.

| File | Arrangement |
| --- | --- |
| `hero.jpg` | Panoramic rose and ranunculus arrangement against a plum backdrop |
| `roses.jpg` | Blush-wrapped pink roses |
| `tulips.jpg` | Apricot tulips in peach wrap |
| `meadow.jpg` | Lavender and white meadow bouquet |
| `lilies.jpg` | Ivory lilies in cream wrap |

Iranian observances use the CC0 Iranian records in [Persian Calendar events](https://github.com/persian-calendar/events), based on the official 1405 Iranian calendar. Lunar month lengths are calendar facts from the [Iranian Islamic date tables](https://github.com/persian-calendar/calendar) and [Qamari](https://github.com/roozbehp/qamari).

Earlier header controls were inspired by [Polad Charkhesh](https://github.com/mosish/polad-charkhesh/tree/main/components/platform).
